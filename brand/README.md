# TastyTrip 로고 파일

앱 인트로 화면에 나오는 마크를 그대로 옮긴 것이다. 앱에서는 이 모양이
그림 파일이 아니라 코드(`lucide-react` 의 `Utensils` + `Plane`)로 그려지므로,
발표 자료처럼 앱 밖에서 쓰려면 여기 있는 파일을 쓴다.

| 파일 | 크기 | 쓰는 곳 |
|---|---|---|
| `tastytrip-mark.svg` | 벡터 | 아무리 키워도 안 깨짐. 인쇄물, 큰 포스터 |
| `tastytrip-mark-512.png` | 512×512 | 발표 자료 본문, 작게 쓸 때 |
| `tastytrip-mark-1024.png` | 1024×1024 | 발표 자료 표지처럼 크게 쓸 때 |
| `tastytrip-logo.svg` | 벡터 | 마크 + 이름 (가로형) |
| `tastytrip-logo-1680.png` | 1680×440 | 표지 슬라이드 제목 자리 |

PNG 는 **배경이 투명**하다. 어떤 색 슬라이드에 올려도 흰 네모가 따라붙지 않는다.

## PPT 에는 PNG 를 쓰는 편이 안전하다

`tastytrip-logo.svg` 의 글자는 글꼴 이름으로만 지정돼 있어서, 여는 컴퓨터에
Inter 가 없으면 다른 글꼴로 보인다. PNG 는 이미 그려진 그림이라 어디서 열어도
똑같다.

## 색

| 이름 | 값 | 어디에 |
|---|---|---|
| primary | `#f05a32` | 마크 왼쪽 위, 'Trip' 글자 |
| primary2 | `#ff7b4f` | 마크 오른쪽 아래 (그라데이션 끝) |
| ink | `#241815` | 'Tasty' 글자 |

발표 자료의 강조색을 맞출 때 `#f05a32` 를 쓰면 된다.

## 다시 만들려면

`*.svg` 를 고친 뒤 Chrome 으로 다시 뽑는다. SVG 를 `<img>` 로 불러오면
Chrome 이 막으므로, HTML 안에 내용을 직접 넣어야 한다.
